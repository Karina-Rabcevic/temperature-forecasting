# Temperature Forecasting

Учебный проект по анализу временных рядов и прогнозированию температуры воздуха.

## О проекте

В проекте анализируются исторические данные о температуре и сравниваются три подхода к прогнозированию: SARIMA, XGBoost и LSTM. Результаты моделей оцениваются на тестовых данных с помощью метрик качества прогноза.

## Что реализовано

- Подготовка временного ряда и обработка пропущенных значений
- Анализ стационарности и сезонности данных
- Построение графиков ACF и PACF
- Декомпозиция временного ряда
- Прогнозирование с помощью SARIMA
- Создание временных признаков и прогнозирование с помощью XGBoost
- Обучение нейронной сети LSTM
- Сравнение результатов моделей по метрикам MAE и MAPE
- Визуализация прогнозов и фактических значений

## Технологии

Python, Pandas, NumPy, Matplotlib, Seaborn, Statsmodels, Scikit-learn, XGBoost, TensorFlow, Keras.

## Статус

Учебный проект.
